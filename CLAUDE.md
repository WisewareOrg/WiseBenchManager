# Agent working rules — WiseBenchManager

The global rules in `~/.claude/CLAUDE.md` apply here unchanged. Working conventions for an AI agent
in this repository are below; project rules are not here — [`CONTRIBUTING.md`](CONTRIBUTING.md) is
authoritative on what a change to this repository must do. This file holds only what is specific to
an agent, which is why it is short: a rule CONTRIBUTING.md states does not belong here as well.

- **A delegate escalates every ambiguity; it never invents an answer.** A choice settled only by "the
  code already does it this way" is an invention.
- **Estimates are estimates.** A size an agent derives is labelled so; a budget exists only when one is
  stated explicitly.
